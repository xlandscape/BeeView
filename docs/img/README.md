# Screenshot Placeholders

This folder should contain the following screenshots for the BeeView documentation.
Replace each placeholder image file with an actual screenshot.

| `map-nectar.png` | Map with Nectar layer enabled, showing white-to-red gradient |

## How to capture

1. Open BeeView at `http://localhost:8083`
2. Import simulation runs if not already done
3. Select appropriate runs and layers for each screenshot
4. Use your OS screenshot tool or browser dev tools to capture the relevant area
5. Save as PNG in this folder with the exact filenames listed above
